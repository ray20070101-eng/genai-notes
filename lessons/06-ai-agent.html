第8週 Agent

AI Agent：Reflection、Tool Use、Planning

不只回答一次，而是會檢查、會用工具、會規劃步驟。

本週重點

  • AI Agent：讓 LLM 在迴圈裡自己決定下一步，而不是一問一答。
  • Reflection：產生答案 → 自我評論 → 修改，直到合格。
  • Tool Use：讓模型呼叫函式（計算機、搜尋、API）。
  • Planning：先把大任務拆成小步驟，再一步步執行。

核心概念

三種模式的共同點是「把 LLM 放進流程裡」。以 Reflection 為例，可以用兩個角色：寫手產生內容、審稿者依評分標準挑毛病，寫手根據意見修改，審稿者回傳 PASS 才結束。

要注意設定最大輪數，避免無限迴圈燒光 API 額度。

比喻Reflection 像交報告前先給學長看過、改完再給他看；Tool Use 像算數學時拿計算機；Planning 像出遊前先排行程。

實作流程

  1. 從老師的 Demo07a/b/c 挑一種模式。
  2. 定義任務與評分標準。
  3. 寫出 寫手 → 審稿 → 修改 的迴圈，設定最大輪數。
  4. 把每一輪的版本都印出來，看得出改進過程。
  5. 接上 Gradio 展示，並調整 prompt 讓行為更穩定。
draft = writer(task)
for round in range(MAX_ROUNDS):
    feedback = critic(task, draft)
    if feedback.strip().startswith("PASS"):
        break
    draft = writer(task, draft, feedback)
return draft

我的作業

我選 Reflection（改自 Demo07a），主題是「讀書筆記整理」：把雜亂的筆記整理成重點，審稿者檢查完整性和格式，多輪反思直到 PASS。

踩雷與提醒

審稿者太好說話評分標準要具體，不然第一輪就 PASS，看不出 Reflection 的效果。
要看得出流程高分需要在程式流程和輸出結果中，清楚看到選的方法真的有在運作。
