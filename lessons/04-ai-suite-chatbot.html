第6週 對話機器人

用 AI Suite 打造有人設的對話機器人

System prompt 決定它是誰，Gradio 讓大家都能跟它聊。

本週重點

  • AI Suite 用同一套寫法呼叫不同廠商的 LLM，換模型只要改一個字串。
  • System prompt 是寫給模型的人設與規則，使用者看不到。
  • Gradio 幾行程式就能做出網頁聊天介面。
  • API key 要自己申請，不能寫死在公開的程式裡。

核心概念

對話機器人每一輪都會把「system prompt＋過去的對話＋這次的訊息」一起送給 LLM。所以人設寫得越具體（背景、說話方式、遇到什麼情況怎麼反應），角色就越穩定。

聊天紀錄要自己存在一個 list 裡傳回去，模型本身不會記得上一句。

比喻System prompt 像給演員的角色設定集，使用者的訊息是對手戲的台詞。設定集寫得越細，演員越不會出戲。

實作流程

  1. 和生成式 AI 討論，把人設背景寫完整。
  2. 申請 API key，用 Colab 的 Secrets 存放。
  3. 修改老師的 Colab 範例，import 老師指定的套件。
  4. 把人設放進 system 訊息，接上 Gradio ChatInterface。
  5. 測試多輪對話並截圖。
import aisuite as ai
client = ai.Client()

def reply(message, history):
    messages = [{"role": "system", "content": PERSONA}]
    for user, bot in history:
        messages += [{"role": "user", "content": user},
                     {"role": "assistant", "content": bot}]
    messages.append({"role": "user", "content": message})
    r = client.chat.completions.create(model=MODEL, messages=messages)
    return r.choices[0].message.content

gr.ChatInterface(reply).launch()

踩雷與提醒
