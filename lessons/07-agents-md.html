第9週 開發工具

AGENTS.md / CLAUDE.md：給 AI 的專案說明書

把規則寫下來，AI 每次都能照同一套方式接著做。

本週重點

  • AGENTS.md / CLAUDE.md 是放在專案根目錄、寫給 AI 看的說明文件。
  • 內容包含：專案目的、風格、檔案結構、命名規則、新增內容的步驟、AI 要遵守的規則。
  • 和 Vibe Coding 的差別：不是做出一頁，而是建立一套能重複使用的製作方式。
  • 這個講義站本身就是作業成果。

核心概念

AI 每次開新對話都會忘記上次的約定。把規則寫成 CLAUDE.md，Claude Code 會自動讀取；AGENTS.md 則是 Codex 等工具慣用的名稱，我讓它指向 CLAUDE.md，兩邊都通用。

好的規則要具體到可以檢查：例如「檔名用 NN-keyword.html」「每篇一定有七個區塊」，而不是「保持整齊」。

比喻像給新進工讀生的交接手冊：寫得夠清楚，任何人（或任何 AI）來都能做出一樣品質的東西。

實作流程

  1. 決定專案：生成式 AI 課程講義站。
  2. 寫 CLAUDE.md：目的、檔案結構、命名、新增步驟、固定區塊、標籤、風格、AI 規則、自我檢查清單。
  3. 做共用的 style.css、lessons.js 和講義模板。
  4. 照規則讓 AI 產生每一篇講義。
  5. 上傳 GitHub、開 GitHub Pages。
## 4. 新增一篇講義的固定步驟
1. 複製 templates/lesson-template.html 到 lessons/NN-keyword.html
2. 把所有佔位文字換成實際內容，不能留下任何佔位符
3. 在 assets/lessons.js 的 LESSONS 陣列最後面加一筆
4. 不需要改 index.html，首頁會自動產生卡片

我的作業

以後要新增第 12 週的講義，只要跟 AI 說「依照 CLAUDE.md 新增一篇第 12 週 Diffusion 的講義」，AI 就會複製模板、照七個固定區塊寫內容、用對的檔名、在 lessons.js 加一筆，首頁和上一篇／下一篇都會自動更新。

踩雷與提醒

規則寫太抽象「風格一致」AI 做不到；「只能用 style.css 的 CSS 變數」才做得到。
首頁要手動改很容易漏所以我把清單集中在 lessons.js，首頁和上下篇都從這裡讀。
